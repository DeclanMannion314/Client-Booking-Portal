# GG Floorscreeds Booking App

A simple booking and job tracking tool built for GG Pumped Floorscreeds. Clients submit a job request through a form, the owner gets an instant email, and every request can be tracked through to completion on a mobile friendly dashboard with a calendar view.

## Live site

- **Booking form**: https://gg-floorscreeds-bookings.onrender.com
- **Dashboard**: https://gg-floorscreeds-bookings.onrender.com/dashboard.html

## Features

- Clients submit job requests (name, phone, job type, address, size, preferred date, notes)
- Instant email notification on every new booking
- Password protected dashboard to view, update, and delete jobs
- Job status tracking (New, Contacted, Scheduled, Done)
- Calendar view showing jobs by scheduled date
- Data stored in MongoDB, so nothing is lost on redeploy

## Tech stack

Node.js, Express, MongoDB, vanilla HTML/CSS/JavaScript.
